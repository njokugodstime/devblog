# DevBlog

A multi-author blogging platform built with plain PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Multi-author system with role-based access (admin, author)
- Authors can write, edit, delete, and publish/draft their own posts with image uploads
- Category-based post filtering
- Public commenting on posts
- Admin panel: manage all posts, manage user roles, moderate comments

## Tech Stack
- PHP (procedural, PDO for database access)
- MySQL
- HTML, CSS, JavaScript
- Git/GitHub for version control

## Setup
1. Clone the repo
2. Import `database/schema.sql` into MySQL
3. Update `includes/db.php` with your database credentials
4. Point Apache to the `public/` folder
